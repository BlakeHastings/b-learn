# blearn

Learn any topic as a graph of evidence-backed concepts you can dive into and climb back out of. Every fact cites a source; your own AI agent does the research.

```sh
npx blearn
```

This opens b-learn in your browser. Pick a topic, then attach the agent you already use (Claude Code, Codex, Cursor, Gemini CLI, or any agent that can run shell commands) by pasting the line the app gives you.

No .NET or other runtime is needed: npm installs a single self-contained binary for your platform (Windows, macOS, Linux; x64 and ARM64).

Source, docs and issues: https://github.com/BlakeHastings/b-learn
